이 문서는 손으로 쓰지 않는다 — 컨트롤러 테스트가 실제 요청·응답으로 만든 openapi3.json을 읽어 그린다.

openapi3.json 을 읽지 못했다. 둘 중 하나다.

① 아직 만들지 않았다 — 스펙은 테스트가 만드는 생성물이라 저장소에 커밋되지 않는다. 먼저 만든다. 
./gradlew :api-app:copyApiSpec
② file:// 로 열었다 — 브라우저가 로컬 파일 fetch 를 막는다. 정적 서버로 연다. 
python3 -m http.server 8000 -d api-docs
# http://localhost:8000 접속
